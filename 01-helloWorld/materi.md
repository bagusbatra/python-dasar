# 👋 Hello World di Python

Ini adalah program pertama yang hampir selalu dibuat saat belajar bahasa pemrograman.

---

# 🎯 Tujuan

* Menjalankan program Python pertama
* Memahami fungsi `print()`

---

# 🧠 Apa itu `print()`?

`print()` adalah fungsi untuk **menampilkan output ke layar**

---

## 💡 Contoh Program

```python
print("Hello World")
```

---

## ▶️ Cara Menjalankan

1. Buat file:

```text
hello.py
```

2. Isi dengan kode di atas

3. Jalankan di terminal:

```bash
python hello.py
```

---

## 🎉 Output

```text
Hello World
```

---

# 🔍 Penjelasan Kode

```python
print("Hello World")
```

* `print()` → perintah untuk menampilkan
* `"Hello World"` → teks yang ditampilkan

---

# 💡 Contoh Lain

```python
print("Nama saya Bagus")
print("Saya sedang belajar Python")
```

---

## 🎉 Output

```text
Nama saya Bagus
Saya sedang belajar Python
```

---

# ⚠️ Error yang Sering Terjadi

## ❌ Lupa tanda kutip

```python
print(Hello World)
```

👉 Error karena teks harus diapit `" "` atau `' '`

---

## ❌ Salah penulisan

```python
pritn("Hello")
```

👉 Harus `print`, bukan `pritn`

---

# 💡 Komentar di Python

Komentar adalah catatan dalam kode yang tidak akan dijalankan oleh program.

Digunakan untuk:
* Menjelaskan kode
* Memberi keterangan
* Membantu programmer lain memahami kode

```
# Ini adalah komentar
print("Hello World")  # menampilkan teks ke layar
```

### 📌 Penjelasan

```
tanda # digunakan untuk membuat komentar
Semua teks setelah # akan diabaikan oleh Python
```

---
