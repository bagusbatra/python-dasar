# 📝 Latihan Hello World

Kerjakan latihan berikut:

---

## 🟢 Soal 1 (Mudah)

Tampilkan teks:

```text
Halo Dunia
```

---

## 🟡 Soal 2 (Sedang)

Tampilkan:

```text
Nama saya: [nama kamu]
Saya belajar Python
```

---

## 🔴 Soal 3 (Sedikit Berpikir)

Tampilkan 3 baris:
```
Nama : [nama lengkap]
Alamat :[alamat] 
Hobi : [hobi]
```
---

# 📂 Simpan File

Contoh:

```text
latihan01.py
```

Simpan di sub-folder [WAJIB DIBERI NAMA]:

```text
pengumpulan/nama_kamu/
```

---

# 🚀 Challenge

Buat output seperti ini:

```text
************************
*   HELLO PYTHON 🚀   *
************************
```

💡 Gunakan `print()` saja
💡 Jangan lupa diberi komentar setiap kode dari soal pertama hingga challenge
