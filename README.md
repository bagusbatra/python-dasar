# 🧑‍💻 Cara Menggunakan Repo Ini

## 🔽 1. Fork Repository

Klik tombol **Fork** di pojok kanan atas

---

## 📥 2. Clone ke Laptop

```bash
git clone https://github.com/USERNAME/python-dasar.git
```

---

## 📂 3. Masuk ke Folder

```bash
cd python-dasar
```

---

## ✍️ 4. Kerjakan Materi & Latihan

* Buka folder sesuai materi
* Pelajari `materi.md`
* Kerjakan `latihan.md`

---

# 📤 Aturan Pengumpulan Tugas

## 📁 1. Buat Folder Nama

Simpan tugas di:

```bash
pengumpulan/nama_kamu/
```

Contoh:

```bash
pengumpulan/bagus/
```

---

## 📝 2. Simpan File

Contoh:

```bash
latihan1.py
latihan2.py
```

---

## 💾 3. Commit Perubahan

```bash
git add .
git commit -m "tugas python dasar - [nama]"
```

---

## 🚀 4. Push ke Repository

```bash
git push origin main
```

---

## 🔁 5. Kirim Pull Request

* Buka GitHub
* Klik **Compare & Pull Request**
* Kirim ke repo utama

---

# ⚠️ Rules (WAJIB DIIKUTI)

## ❌ **Dilarang**:

* Copy paste dari teman
* Menggunakan AI tanpa memahami kode
* Mengumpulkan tugas kosong

---

## ✅ Wajib:

* Tulis kode sendiri
* Beri komentar setiap bagian kode
* Beri nama file yang jelas
* Gunakan commit message yang rapi

---

## 💡 Contoh Commit yang Baik:

```bash
git commit -m "menyelesaikan latihan perulangan"
```
