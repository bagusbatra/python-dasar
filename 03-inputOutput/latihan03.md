# 📝 Latihan Input & Output

Kerjakan latihan berikut:

---

## 🟢 Soal 1 (Mudah)

Buat program yang meminta input:
- nama

Lalu tampilkan:

```text
Halo [nama]
```

---

## 🟡 Soal 2 (Sedang)

Buat program:
- input nama
- input umur

Tampilkan:

```text
Nama saya [nama]
Umur saya [umur] tahun
```

---

## 🔴 Soal 3 (Berpikir)

- Buat program untuk menghitung luas segitiga, dengan variabel :
- Wajib menggunakan fungsi `print()` serta `input()` 
    - alas
    - tinggi

lalu tampilkan
```text
=== LUAS SEGITIGA ===
alas  : 6 cm
tinggi  : 10 cm
luas : 30 cm2
====================
```
