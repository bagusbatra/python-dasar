# 📝 Latihan Variabel

Kerjakan latihan berikut:

---

## 🟢 Soal 1 (Mudah)

Buat variabel:

* username
* email
* password

Lalu tampilkan dengan perintah `print()`

---

## 🟡 Soal 2 (Sedang)

Buat output lagi dari variabel pada soal 1:

```text
Selamat datang [username]
Email anda adalah [email]
Dengan password [password]
```

---

## 🔴 Soal 3 (Berpikir)

* Buat variabel `nama`, `umur` dan `hobi`:
* Tampilkan seperti dibawah ini

```text
===== DATA DIRI =====
Nama  : Bagus
Umur  : 17
Hobi  : Coding
====================
```

---

# 🚀 Challenge

Buat program dengan output:
* produk
* jumlah
* harga

Tampilkan semua seperti hasil dibawah ini :

```text
===== PESANAN =====
Produk  : Shampoo
Jumlah  : 17
Harga  : 2500
TOTAL PESANAN : Rp. 42500,00
====================
```
