## 📌 Tugas Utama

Buat program:

# 🎯 **Sistem Data Siswa Sederhana**

---

## 🧩 Fitur Wajib

Program harus memiliki:

### 1. Menampilkan Menu
Contoh:
```text
1. Lihat Data
2. Tambah Data
3. Hapus Data
4. Keluar
```

---

### 2. Menampilkan Data Siswa
Format:
```text
Andi - 7A - 80 - Lulus
```

---

### 3. Menambah Data Siswa
Input:
- nama
- kelas
- nilai

---

### 4. Menghapus Data Siswa
Berdasarkan nama

---

### 5. Status Kelulusan
Ketentuan:
- ```nilai >= 75 → Lulus```
- ```nilai < 75 → Tidak Lulus```
