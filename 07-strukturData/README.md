# 📦 07 - Struktur Data

## 🎯 Tujuan Pembelajaran
Pada materi ini, kamu akan belajar:
- Apa itu struktur data
- Menyimpan banyak data dalam Python
- Menggunakan:
  - List
  - Tuple
  - Set
  - Dictionary
  - Nested Data (data bersarang)

---

## 🧠 Kenapa Ini Penting?

Saat program mulai kompleks, kita akan butuh:
- menyimpan banyak data
- mengelola data
- memproses data

Contoh:
- data siswa
- nilai
- daftar barang

👉 Semua itu tidak bisa pakai 1 variabel saja

---

## 📚 Materi

Pelajari secara berurutan:

1. [LIST](./list.md) → dasar menyimpan banyak data  
2. [TUPLE](./tuple.md) → data tetap (tidak bisa diubah)  
3. [SET](./set.md) → data unik (tanpa duplikat)  
4. [DICTIONARY](./dictionary.md) → data key & value  
5. [NESTED](./nested.md) → kombinasi semua struktur data
