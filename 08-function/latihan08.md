# 📝 Latihan Function

Kerjakan latihan berikut untuk melatih pemahaman tentang:
- Function
- Parameter
- Return

---

## 🟢 Soal 1 (Mudah)

Buat function:

- ```sapa(nama)```

Tampilkan:
```text
Halo Andi
```

Panggil function dengan 5 nama berbeda

## 🟡 Soal 2 (Sedang)

- return

## 🔴 Soal 3 (Berpikir)

Buat function:

- ```rata_rata(nilai)```

Ketentuan:
- ```nilai berupa list```
- nilai didapatkan dari input (loop)
- jika input `0` maka nilai akan dihitung
- hitung rata-rata menggunakan return

# 🚀 Challenge (Level Hard 🔥)

Buat program **Sistem Nilai Siswa (Versi Function)**

---

## 🎯 Data:

```python
data = [
    {"nama": "Andi", "nilai": 80},
    {"nama": "Budi", "nilai": 60},
    {"nama": "Citra", "nilai": 90}
]
```

---

## 🧠 Tugas:

### 1. Buat function:
```cek_lulus(nilai)```

Return:
- ```"Lulus"``` jika >= 75
- ```"Tidak Lulus"``` jika < 75

---

### 2. Buat function:
```rata_rata(data)```

Return:
- rata-rata nilai seluruh siswa

---

### 3. Tampilkan semua data siswa

Format:
```text
Andi - 80 - Lulus
```

(Gunakan function ```cek_lulus```)

---

### 4. Tampilkan rata-rata nilai

(Gunakan function ```rata_rata```)

---

## ⚠️ Ketentuan Wajib

- Gunakan:
  - function
  - parameter
  - return
  - list & dictionary
  - perulangan (for)
