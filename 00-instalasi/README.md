# 🐍 Instalasi Python (Windows)

Pada materi ini, kamu akan belajar cara **menginstall Python** sampai siap digunakan untuk coding.

---

# 🎯 Tujuan

Setelah materi ini, kamu harus bisa:

* Menginstall Python
* Menjalankan Python di terminal
* Menjalankan file `.py`

---

# 💻 1. Download Python

Buka website resmi:
👉 https://www.python.org

Klik:
👉 **Download Python (versi terbaru)**

---

# 📦 2. Install Python

## ⚠️ LANGKAH PALING PENTING

Saat install, **WAJIB centang**:

```text
✅ Add Python to PATH
```

---

## 🔽 Langkah Install

1. Buka file installer
2. Centang **Add Python to PATH**
3. Klik **Install Now**
4. Tunggu sampai selesai

---

# ✅ 3. Cek Instalasi

Buka:

* CMD / Command Prompt
* atau PowerShell

Ketik:

```bash
python --version
```

---

## 🎉 Jika Berhasil

Akan muncul:

```bash
Python 3.x.x
```

---

## ❌ Jika Gagal

Jika muncul:

```text
python is not recognized
```

👉 Artinya:

* Python belum terinstall dengan benar
* Atau PATH belum aktif

---

## 🔧 Solusi:

* Restart komputer
* Install ulang dan pastikan centang **Add Python to PATH**

---

# ▶️ 4. Menjalankan Python

Ketik di terminal:

```bash
python
```

---

## 🎉 Jika berhasil:

Akan muncul seperti ini:

```text
>>>
```

👉 Ini disebut **Python Interactive Mode**

---

## 🚪 Keluar dari Python:

```bash
exit()
```

---

# 📄 5. Menjalankan File Python

## 📝 Buat file:

Contoh:

```text
halo.py
```

---

## ✍️ Isi file:

```python
print("Hello World")
```

---

## ▶️ Jalankan:

```bash
python halo.py
```

---

## 🎉 Output:

```text
Hello World
```

---

# 📂 Rekomendasi Tools

Gunakan editor berikut:

* VS Code (disarankan)
* Notepad++
* atau editor lainnya

---

# ⚠️ Error yang Sering Terjadi

## ❌ Python tidak dikenali

👉 Solusi: install ulang + centang PATH

---

## ❌ Salah penulisan perintah

```bash
pyhton halo.py ❌
python halo.py ✅
```

---

## ❌ File tidak ditemukan

👉 Pastikan posisi folder benar

---

# 💡 Tips Penting

* Gunakan folder khusus belajar Python
* Gunakan nama file sederhana
* Jangan pakai spasi di nama file

---

# 🧠 Kesimpulan

Langkah instalasi:

1. Download Python
2. Install (WAJIB centang PATH)
3. Cek dengan `python --version`
4. Jalankan Python
5. Jalankan file `.py`
